# Screenshots

Images referenced from pull requests live here, one folder per branch:

```
docs/screenshots/<branch-slug>/<description>.png
```

Link them from the pull request with a URL pinned to the commit, so the image
keeps working after the branch is squash merged and deleted:

```
https://github.com/<owner>/TubeTiles/blob/<commit-sha>/docs/screenshots/<branch-slug>/<description>.png?raw=true
```
